# Badge

Badge is an Android budgeting app that makes tracking expenses fast. Instead
of opening the app every time you spend money, you log it from a home-screen
widget in a single tap.

## Features

- **Dashboard:** see how much you've spent today, this week, and this month,
  plus your recent expenses.
- **Quick-add buttons:** customizable one-tap buttons for common spending,
  like commute fare or coffee, each with its own amount and category.
- **Custom amounts:** enter any amount with a numbers-only keyboard.
- **Budgets:** set limits per day, week, month, or year, for all spending or
  for a specific category, and watch the progress bars fill.
- **Custom categories:** create categories like Food, Transport, or
  Miscellaneous.
- **Home-screen widget** *(in progress)*: add expenses without opening the app.

## Planned

- Export expenses to CSV and Google Sheets
- Budget alerts
- Spending charts by category

## Built with

Kotlin, Jetpack Compose, Room, and Jetpack Glance.

## Getting started

1. Clone this repository.
2. Open it in Android Studio.
3. Let Gradle sync, then run the app on an emulator or a physical device.
